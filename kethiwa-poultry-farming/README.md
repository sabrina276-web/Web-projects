 # Kethiwa Poultry Farming

A professional website demo designed for Kethiwa Poultry Farming in Nanyuki, Kenya.

## Project Overview

The website was designed to give the poultry business a professional online presence and make it easier for customers to learn about the farm and place orders.

## Features

- Poultry farm information
- Chick vaccination information
- Gallery
- Branch locations
- Contact information
- WhatsApp ordering
- Responsive design
